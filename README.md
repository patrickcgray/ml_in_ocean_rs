# ml_in_ocean_rs

Code examples for the manuscript "The Pitfalls and Promise of Machine Learning in Ocean Remote Sensing"

This code is most easily run by pulling the pangeo docker container and running it via a jupyter lab with the following command

`docker run -it -v <your local code location>:/home/jovyan --rm -p 8888:8888 pangeo/pangeo-notebook:2024.08.18  jupyter lab --ip 0.0.0.0`
